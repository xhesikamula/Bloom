# 🌸 Bloom - Flower Shop Website

**Bloom** is a modern, responsive flower shop website built with **HTML5** and **CSS3**. It showcases a clean, elegant design tailored for selling flowers online, providing users with a pleasant and visually appealing experience.

## 🌼 Features

- Beautiful and responsive design
- Homepage with promotional banners
- Product listings with flower images and descriptions
- Fully built using HTML5 and CSS3 (no JavaScript)
- Easy to navigate layout

## 🚀 Getting Started

To run this project locally:

1. Clone the repository: git clone https://github.com/xhesikamula/Bloom.git
2. Open `index.html` in your browser.

No setup or installation required — just pure front-end code.

## 🎯 Purpose

This project was created to practice modern front-end development using HTML5 and CSS3 only. It focuses on responsive layout, clean UI/UX design, and semantic HTML structure.
